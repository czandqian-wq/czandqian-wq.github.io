# 陈壮的个人网站

一个记录土木工程研究、AI 数据训练学习、项目实践与成长路线的个人网站。

在线访问：[https://czandqian-wq.github.io](https://czandqian-wq.github.io)

## 主要内容

- 个人介绍与经历
- AI 数据训练师转型方向
- 项目案例与公开路线图
- 滚动生长的数据树
- 可互动的数据精灵
- AI 术语翻卡
- 深色、浅色主题及移动端适配

## 本地运行

需要 Node.js `22.13.0` 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000` 查看网站。

## 检查与构建

```bash
npm run lint
npm test
npm run export:pages
```

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。
