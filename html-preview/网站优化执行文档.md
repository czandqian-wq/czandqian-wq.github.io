## 一、维护原则

网站不再以 `index-v2.html` 为主文件。后续修改按职责拆分：

| 文件 | 作用 | 后续主要修改内容 |
|---|---|---|
| `app/content.ts` | 内容数据 | 名字、介绍、项目、待办和联系方式 |
| `app/page.tsx` | 页面组件与交互 | 弹窗、筛选、主题、看板、复制按钮 |
| `app/globals.css` | 视觉与响应式 | 配色、排版、动效、手机适配 |
| `app/layout.tsx` | 页面元信息 | 标题、描述、图标和分享信息 |

版本回退使用 Git 提交，不再复制多个主项目文件。`html-preview/index.html` 和 `html-preview/index-v2.html` 仅作为历史参考保留。

## 四、技术实现说明

### 4.1 主题初始化

在 `app/layout.tsx` 的 `<head>` 中加入最小主题初始化脚本，在 React 加载前读取本地主题；`<html>` 使用 `suppressHydrationWarning`，避免主题属性导致水合警告。

### 4.2 弹窗交互

`app/page.tsx` 记录触发弹窗的按钮。打开时锁定页面滚动；关闭时恢复滚动并把焦点还给触发按钮。Escape 统一调用同一个关闭函数。

### 4.3 滚动与光效

滚动进度通过 DOM 引用与 `requestAnimationFrame` 更新，不把每次滚动写入 React state。卡片光效通过 CSS 自定义属性保存鼠标位置，并只在桌面精细指针设备上响应。

### 4.4 内容维护

所有待填写字段继续集中在 `app/content.ts`。当内容准备好后，只替换数据，不改页面结构。
